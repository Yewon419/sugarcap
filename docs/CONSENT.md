확정 후 en·zh-Hant 번역, 개인정보처리방침 3개 언어판(`site/privacy/`, `site/en/privacy/`, `site/zh-Hant/privacy/`)의 "수집하지 않는 것" 절 개정, `docs/STORE.md` §6 App Privacy 답을 같은 내용으로 맞춘다.

근거로 삼은 것: 개인정보 보호법 제15조 제2항(동의 시 알릴 4가지: 목적·항목·보유 기간·거부 권리와 불이익), 제28조의8(국외 이전 시 알릴 사항). 수집 항목은 이름·연락처 없이 무작위 식별값만 쓰지만, 이용자 신뢰를 위해 개인정보 수집 동의와 같은 형식과 수준으로 고지한다.

## 1. 화면 구성

- 제목과 요약 표를 먼저 보여 주고, 그 아래 "전문 보기"를 펼치면 2절 전문이 나온다.
- 두 버튼은 같은 크기와 같은 무게로 나란히 둔다. 한쪽만 강조하지 않는다.
- 닫기(X)는 두지 않는다. 고르지 않고 앱을 끄면 다음 실행 때 다시 묻는다.

### 제목
**[선택] 서비스 개선을 위한 이용 기록 수집·이용 동의**

| 수집 항목 | 앱 이용 기록, 음료 기록(메뉴·잔 수·요일·시간대), 무작위 생성 식별값, 앱 버전·운영체제 버전·언어·지역 설정 |

### 버튼
`동의합니다` / `동의하지 않습니다`

### 설정 화면 스위치
- 라벨: `이용 기록 제공(선택)`
- 아래 설명 한 줄: `서비스 개선을 위한 이용 기록 수집·이용에 동의합니다.` + `전문 보기` 링크(2절)
- 끄면 확인 없이 바로 꺼지고, 그 뒤로 보내지 않으며 기기에 쌓여 있던 미전송 기록도 지운다.

## 2. 전문

### 제1조 (목적)
슈가캡(이하 "앱")의 운영자는 앱 기능을 개선하고 음료 메뉴 데이터를 보완하기 위하여, 이용자의 동의를 받아 아래와 같이 이용 기록을 수집·이용합니다. 이 동의는 선택 사항입니다.

### 제2조 (수집·이용 목적)
1. 앱 기능과 화면의 이용 흐름 분석 및 개선
2. 앱에 없는 음료 메뉴 파악과 메뉴 데이터 보완
3. 음료 종류·요일·시간대별 이용 통계 작성

수집한 정보는 위 목적 외의 용도로 이용하지 않으며, 광고·마케팅 목적으로 이용하거나 제3자에게 판매하지 않습니다.

### 제3조 (수집 항목)
1. **앱 이용 기록:** 처음 사용 안내 완료 여부, 음료 기록 방법(검색·브랜드 메뉴·즐겨찾기·최근 기록·직접 입력의 구분), 하루 마감 진행 여부, 구독 안내 화면의 표시와 선택 결과, 줄이기 목표·마감 알림·위젯 사용 여부
2. **음료 기록:** 앱 메뉴 데이터의 음료 식별값, 잔 수, 기록한 요일과 시간대(정각 단위), 메뉴 국가, 하루 기준량의 범위, 하루 기준량 안에서 마쳤는지 여부, 직접 입력한 음료의 잔 수, 기록 항목(당·카페인) 설정
3. **무작위 생성 식별값:** 앱 설치 시 무작위로 만든 값과 앱을 실행할 때마다 새로 만드는 값으로, 이용 흐름을 잇는 데만 씁니다. 기기에서 변환(해시)한 뒤 보내며, 기기 고유번호나 광고 식별자가 아닙니다. 음료 기록(제2호)에는 이 값을 붙이지 않습니다.
4. **기술 정보:** 앱 버전, 운영체제 버전, 언어·지역 설정

다음 정보는 수집하지 않습니다: 이름, 연락처, 이메일, 위치, 사진, 광고 식별자, 직접 입력한 음료 이름, 음료를 기록한 정확한 시각, 기록 하나하나의 당·카페인 양.

### 제4조 (보유 및 이용 기간)
수집한 정보는 수집일로부터 2년 동안 보유·이용하며, 기간이 끝나거나 이용자가 동의를 철회하면 지체 없이 파기합니다. 다만 이미 보낸 정보에는 이용자를 알아볼 수 있는 값이 없어 이용자별로 골라 지울 수 없으므로, 동의 철회 이후에는 새로 수집하지 않는 방식으로 처리합니다.
